# Support

Choose the channel that best matches your request:

- For usage, build, configuration, or API help, open a
  [support question](https://github.com/kaix-huang/Zynum/issues/new?template=question.yml).
- For reproducible incorrect behavior, open a
  [bug report](https://github.com/kaix-huang/Zynum/issues/new?template=bug_report.yml).
- For a new capability or design proposal, open a
  [feature request](https://github.com/kaix-huang/Zynum/issues/new?template=feature_request.yml).
- For a suspected vulnerability, do not open a public issue. Follow the private
  reporting process in [SECURITY.md](SECURITY.md).

Support is provided on a best-effort basis. Include the Zynum and Zig versions,
operating system, CPU and target, relevant commands or code, expected result,
and complete error output when applicable. Remove credentials and other private
information before posting.
